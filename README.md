# CorpVEX Page

Official Sales, Pricing & Free Tools Landing Website for **CorpVEX ERP** — Next-Gen Enterprise Suite for Garment, Wholesale & Modern Trade.

## Live Website
🌐 [https://corpvex.netlify.app](https://corpvex.netlify.app)

## Features Included
- 🚀 **Interactive ERP Sandbox**: Invoicing table, stock register, real-time trial balance, A4 Tax Invoice preview.
- 💳 **Pricing Module**: Starter, Growth, and Conglomerate plans with 11-feature Capability Matrix table.
- 🛠️ **50+ Free Tools & Calculators Suite**: GST, TDS/TCS, HSN Finder, Margin, QR/Barcode generators, etc.
- ⚡ **Standalone & Self-Contained**: Single production HTML bundle with SPA client-side routing.

## Building / Updating
```bash
node build-html.mjs
```
